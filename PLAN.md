# re3-rs plan

Rust rewrite of re3 (GTA III, `re3-REDUX/re3-master`) and reVC (Vice City, branch `main-miami`, dir `re3-miami`).

## Decisions
- Incremental: port bottom-up, link into the C++ build over a C ABI, drop C++ when the last piece lands.
- One engine, games selected by Cargo features `gta3` / `vc`; one fixed PC config (`FIX_BUGS` on, no PS2 paths).
- Rendering via `wgpu` (Vulkan/GL/DX12/Metal); windowing via `winit`. Linux + Windows.
- Binaries (gta3.exe / gta-vc.exe) are checked later with REA to find missing functions.

## Releases
One `main` branch, three releases from it, named Re3 (GTA III), re3 Miami (Vice City) and Re3 LA (San Andreas): tags `re3-vX.Y.Z`, `re3-miami-vX.Y.Z`, `re3-la-vX.Y.Z`, each a GitHub Release with that game's binaries (built by `--features` / game flag in the phase 8 binary crates). C++ reference lives outside the repo in ~/Projects/re3-cpp-reference.

7. renderer + RenderWare replacement
8. core/skel: main loop, input, frontend

## Renderer design (decided 2026-10-26)
- Rendering is wgpu (a proof of concept drew a textured Landstalker from the real gta3.img on the RX 6700 XT; scratch project in ~/Projects/render-poc, outside the repo; librw was tried as the alternative and not pursued).
- Two looks, one renderer: the FAITHFUL look is built first and is the reference we verify against the original; the ENHANCED look is the default out of the box and is a set of layers on top of it. A menu toggle ("Classic" / "Enhanced") switches all enhancements off at once, and each enhancement can also be switched on its own.
- Enhanced look, in order of cost: texture filtering (mipmaps, anisotropic), widescreen/HUD scaling, high resolution and high frame rate (logic keeps its own tick, drawing is interpolated), HDR/tone mapping/bloom, nicer sky and fog, dynamic lights and shadows (headlights, street lamps) blended with the baked vertex lighting, better water and car reflections, ambient occlusion, loading user-supplied replacement textures (never shipped: they derive from Take-Two's art).
